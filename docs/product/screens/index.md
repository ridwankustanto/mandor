# Screens

One file per screen. Copy `../../_templates/screen-brief.md`, name it
`SCR001-<slug>.md`, and link it here.

The behaviour half is filled in `/pm-flows`, before any visual work. The visual half is
filled in `/pm-design`, after the design system is approved.

```bash
./pm q "SELECT code, name, route, design_status, iterations FROM screen ORDER BY code"
```
